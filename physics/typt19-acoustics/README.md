# 聲學研究工作台｜第19屆 TYPT

工具在使用者瀏覽器內運行，音檔不傳到伺服器；不含後端、帳號登入、外部分析API或追蹤程式。

## 官方題目與研究策略

第19屆TYPT採2027年IYPT題，排除第7、8、10、13、14題，保留官方題號：
- 第4題 Singing capacitor（會唱歌的電容）：對照驅動頻率與聲音各峰、分析倍頻；固定收音條件後比較電壓與數位RMS；可用單模態共振／條件式冪次關係作基線。電壓來源須隔離低壓，勿接市電。
- 第6題 Seeing sound（看見聲音）：掃頻找共振、停驅動後錄自由衰減，與理想張緊圓膜模態頻率比較。音檔不能還原膜面模態或雷射軌跡，需同步影像；鏡片質量、非均勻張力與邊界會使理想模型偏移。雷射勿照眼睛或反射入眼。
- 第11題 Sound isolation（聲音隔離）：同聲源、位置、增益與時間窗錄參考／待測音，以表觀插入損失比較。開口混合模型假設非相干功率疊加與相同傳遞條件；Helmholtz模型只適用小開口—腔體且波長遠大於結構等條件，非任意門縫的通式。
- 第12題 Dotted line trick可用聲音輔助估計黏滑週期，但不是以聲學為主的題目。

官方來源：https://typt.phy.ntnu.edu.tw/home/typt辯論題目.html

## 快速開始

1. 選擇自己的音檔。建議PCM WAV；MP3／M4A／OGG能否解碼依瀏覽器。原生PCM／float WAV保留檔案取樣率；其他格式顯示瀏覽器工作取樣率，可能已重採樣。
2. 設定左右聲道或平均、原檔選段、去直流、可選高／低通、FFT長度與顯示頻段，按「分析」。更改設定後須重新分析，不以舊圖冒充新結果。
3. 同時看波形、中央Hann窗FFT、Welch PSD、STFT時頻、逐窗最強峰與20ms RMS包絡。最強峰不是保證的基頻；近峰可能未解析。
4. 選理論模型、輸入SI單位參數；手動貼入或匯入x,y,sigma CSV，或逐次把錄音觀測加入資料表。比較理論曲線、測值、誤差棒、殘差與RMSE。σ全部有效才計算固定模型的χ²/df。
5. 線性／冪次回歸僅針對同批資料估參，不算獨立模型驗證。冪次擬合的R²及斜率誤差在對數空間；有效已知σ的參數誤差不再依殘差重縮放。
6. 匯出完整頻譜CSV、逐窗主峰／包絡CSV、波形CSV、比較CSV、研究紀錄JSON、處理後16-bit WAV及PNG圖。

## 支援邊界

- 單檔至多80MB、解碼後120秒、1–2聲道且至多1,200萬取樣值。波形CSV最多100萬點；較長音段仍可匯出WAV、頻譜與包絡資料。
- 濾波為因果二階Butterworth型，會有相位及邊界瞬態；不做AI降噪，不自動去掉實驗差異。
- FFT的Δf、Hann等效雜訊頻寬與窗長會顯示；拋物線峰插值不等於真正解析力提高。STFT最多320個時間窗及220個頻率顯示分箱，顯示分箱取最大值，完整PSD仍保留。
- 原檔與處理後數位飽和分開警示，16-bit WAV匯出可能夾限；可聽處理結果，但不能把削波／自動增益／正規化後的振幅差當成材料差異。
- 表觀IL不是標準傳輸損失TL。參考頻段太弱的格點留白；兩檔取樣率或FFT解析度不同時，只保留總RMS比、停用逐頻IL，不虛構插值比較。
- dBFS不是dB SPL；沒有聲壓校正，不輸出絕對Pa或SPL。不提供相位相干度或精確傳遞函數，不能由不同步錄音推算相位。
- 內建三種訊號只供合成測試，明標「非實測」。初開沒有實驗資料，範例公式參數不是本隊量測。
- JSON不含原音訊；請另存原始檔。重新整理後不保留記憶體中的音檔與資料，結束前請匯出。
